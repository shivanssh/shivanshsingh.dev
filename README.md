# Shivansh Singh Portfolio

Professional Senior full stack developer portfolio built with Next.js. It showcases experience, skills, featured projects, certifications, and contact details through a polished responsive interface.

## Overview

This portfolio is designed for a senior UI and frontend developer profile, with emphasis on:

- React.js and Next.js frontend engineering
- Responsive, accessible UI development
- Design-system-minded component structure
- Performance-focused portfolio presentation
- AI-assisted content and UI iteration

## Tech Stack

- Next.js 14
- React.js
- CSS Modules
- JavaScript
- Vercel-ready deployment

## Featured AI-Assisted Workflow

The portfolio project includes AI-assisted iteration using:

- Claude Opus
- Gemini 3.5
- GPT-5.5

These tools were used for theme direction, content refinement, UI iteration, and quality review.

## Getting Started

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```
